# Sidebar font

Roboto variable, normal style, Latin subset (weights 100–900), bundled from
`@fontsource-variable/roboto` version 5.3.0:
https://cdn.jsdelivr.net/npm/@fontsource-variable/roboto@5.3.0/files/roboto-latin-wght-normal.woff2

Licensed under the SIL Open Font License; see `Roboto-LICENSE.txt`.
The private CSS family name `ESS Sidebar` ensures browsers use this asset rather
than a locally installed font. Vite serves it from the app's own origin.
